# Dialog for Google Tag Manager

The Dialog tag template for the [Google Tag Manager Community Template Gallery](https://tagmanager.google.com/gallery/). It runs Dialog on your store (the assistant, the product block) and measures the GA4 e-commerce events your store pushes to the dataLayer, only while GTM reports `analytics_storage` as granted.

Setup guide: https://docs.askdialog.com/installation/google-tag-manager

This repository publishes the template to the gallery. Its source lives in Dialog's main repository (`frontend/dialog-tag/gtm/dialog.tpl`); `template.tpl` here is a copy of it, and each published version is a commit listed in `metadata.yaml`.
